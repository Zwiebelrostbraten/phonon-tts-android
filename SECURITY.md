# Security reporting

Please do not publish exploit details for an unpatched vulnerability in a public issue. Private vulnerability reporting is enabled: use [Security → Report a vulnerability](https://github.com/Zwiebelrostbraten/phonon-tts-android/security/advisories/new). No private email address is designated here.

Include the affected app version, Android version, relevant model/download path, impact and minimal reproduction using harmless data. Never send Hugging Face tokens, signing keys, account credentials, private reading text or unredacted logs. Redact paths and images that identify people.

This is a community-maintained app. Reports should identify the exact stable or preview version; there is no promised support window or response deadline. Maintainers should assess fixes against the current release and document any update requirements. Code, model and voice licensing are separate from security reporting.
